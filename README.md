# MindCare 🌱

A mental health mood tracking app built with **React**, **TypeScript**, **Tailwind CSS**, **Material UI**, and **Framer Motion**.

Track your mood, discover relaxation resources, and get daily inspiration — all in a beautiful, responsive interface with **dark mode** support.

## Features

- **Mood Tracker** — Rate your stress, energy, and positivity with interactive sliders
- **Mood Percentage** — Live score with animated counter and personalized message
- **Dark Mode** — Toggle between light and dark themes (persisted to localStorage)
- **Resource Library** — Curated videos and articles for mental well-being
- **Daily Quote** — Random inspirational reminder in the footer
- **Helplines** — Quick-access crisis helpline numbers
- **Responsive** — Fully mobile-friendly with glassmorphism design
- **Animations** — Smooth scroll-triggered animations with Framer Motion

## Tech Stack

| Tool | Purpose |
|---|---|
| **React 18** | UI framework |
| **TypeScript** | Type safety |
| **Tailwind CSS** | Utility-first styling |
| **Material UI (MUI)** | Sliders, Cards, Buttons, Icons |
| **Framer Motion** | Animations & transitions |
| **Parcel** | Zero-config bundler |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:1234](http://localhost:1234) in your browser.

## Build

```bash
npm run build
```

Output goes to `dist/` — ready for deployment to Vercel, Netlify, or any static host.
